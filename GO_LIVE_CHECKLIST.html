Persiapan Admin

— sekali di awal
  • Login ke Panel Admin (akun admin/superadmin)
  • Pengaturan → Lokasi Kantor: set titik GPS kantor + radius geofence (mis. 100 m) — penentu absen dianggap "di kantor"
  • Departemen/Unit: pastikan semua unit (Kurir, Driver, Inbound/Outbound, dll.) sudah dibuat
  • Jam Kerja / Shift: atur jam masuk–keluar per departemen (termasuk shift malam bila ada)
  • Kuota Cuti: atur jatah cuti tahunan (bila dipakai)
  • Pengaturan Absensi: cek toggle (wajib wajah, wajib GPS, toleransi telat) sesuai kebijakan
  • Pastikan APK terbaru bisa diunduh dari tautan di atas
1

Uji Pilot (1–2 orang)

— WAJIB sebelum rollout

Tujuan: memastikan wajah + GPS + kamera + notifikasi jalan di HP Android asli, di lokasi kantor sungguhan.

Onboarding karyawan uji
  • Buat 1 akun karyawan di Karyawan → Tambah (data asli)
  • Detail Karyawan → bagikan kredensial via tombol Kirim via WhatsApp (atau Salin)
  • Karyawan install APK (izinkan "sumber tak dikenal" bila diminta)
  • Login dengan password sementara → ganti password
  • Izinkan permission HP: Kamera, Lokasi, Notifikasi
  • Daftar wajah (Face ID) di menu profil aplikasi
Uji alur absensi (di lokasi kantor)
  • Absen Masuk: wajah berhasil + GPS "di kantor" → sukses
  • Absen Keluar: berhasil
  • (Opsional) Mode offline: matikan internet → absen → nyalakan → data tersinkron otomatis
  • Pengingat absen muncul (notifikasi sebelum jam masuk/keluar)
Verifikasi di Panel Admin
  • Data absensi muncul di Dashboard & Absensi
  • Foto wajah absen masuk/keluar tampil di Detail Karyawan
  • Statistik & Laporan menghitung kehadiran dengan benar
  • Karyawan bisa lihat Recap Bulanan di aplikasi
Uji cuti & lembur
  • Ajukan cuti → muncul di Kotak Masuk → Setujui → karyawan dapat notifikasi
  • Ajukan lembur → muncul di Kotak Masuk → Setujui/Tolak → notifikasi diterima
  • Uji tolak dengan alasan → karyawan terima alasannya
✅ Bila semua di atas mulus → AMAN untuk rollout ke semua karyawan.
2

Rollout ke Semua Karyawan

  • Buat semua akun karyawan (manual di admin atau seed data)
  • Bagikan kredensial ke tiap karyawan (tombol WhatsApp per orang)
  • Umumkan cara pakai (install → login → daftar wajah → absen)
  • Pantau progres pendaftaran wajah semua karyawan
  • Hari pertama live: pantau Dashboard realtime, siap bantu yang kesulitan
  • Tetapkan PIC HR untuk tangani kendala hari pertama
3

Operasional Harian (HR)

  • Pantau Dashboard kehadiran tiap pagi
  • Proses Kotak Masuk (cuti & lembur) tiap hari — jangan menumpuk
  • Cek inbox Kendala Login & Permintaan Edit Data
  • Balas Chat support karyawan bila ada
  • Akhir bulan: Laporan → Cetak PDF / Excel / Ringkasan Unit untuk manajemen
!

Troubleshooting Umum

Masalah Solusi cepat
Wajah tidak terbaca Daftar ulang wajah; pastikan pencahayaan cukup & wajah jelas
GPS dianggap "jauh dari kantor" Cek radius geofence di Pengaturan → Lokasi Kantor; aktifkan GPS HP (akurasi tinggi)
Tidak bisa login Cek akun di admin; reset/bagikan ulang password sementara
APK tidak ter-install Izinkan "Install dari sumber tak dikenal" di setting HP
Notifikasi tidak masuk Izinkan Notifikasi untuk aplikasi; pastikan tidak dibatasi mode hemat baterai
Pengajuan tidak muncul di admin Pastikan karyawan submit dari aplikasi; refresh halaman Kotak Masuk
~

Opsional (tidak menghambat pemakaian)

  • Email onboarding otomatis (SMTP) — saat ini via WhatsApp/manual (cukup); aktifkan bila ingin email otomatis (perlu App Password Gmail)
  • Auto-deploy (CI/CD) — saat ini deploy manual; tambah secret FIREBASE_TOKEN di GitHub bila ingin publish otomatis tiap perubahan
